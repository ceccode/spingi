# 0028: A scene is checked like a plan: one schema, unknown keys are errors, geometry is looked at

Status: Accepted · Date: 2026-11-24 · Milestone: A1

## Context
ADR-0026 made an unknown key in a plan an error. Scenes had the same hole and a larger one. A scene file had no schema of its own: `scenes.py` read some sections with `raw.get(...)`, the MuJoCo builders read the others, and whatever neither asked for was dropped without a word. `obstacle:` for `obstacles:` left the wall out of the world and the robot walked through where it stood; `max_sped:` in `safety:` left the run without its speed cap. A file that was not a scene ended in a traceback. And the rules that make a scene one a robot can work in, a straight leg that clears the shelving, a stop from which the camera has the gauge in view, a tag ahead of each stop, were prose in the tutorial: people found out by spending a run. Scenes are about to be written by coding agents too (ADR-0030), which follow a schema well and cannot see a mistake a schema does not name.

## Decision
- **One schema, and every reader goes through it.** `SceneFile`, in `spingi.scenes`, declares every section: `robot`, `locations`, `obstacles`, `objects`, `landmarks`, `routes`, `safety`, `terrain`. Every model refuses unknown keys and non-finite numbers and is strict about types: `x: true` or `x: "1"` is not a number. `load_world`, `load_safety_limits` and `load_routes` read through `load_scene`, and so does the simulator (`load_scene_yaml`). `SafetyLimits` and `Geofence` refuse unknown keys themselves, and a fence with its sides swapped.
- **The scene as a whole is checked too.** A marker id names one tag, objects and landmarks together; a route names locations of its scene; the ground reaches as far as the geofence. The limits the simulator's builders check again (cell size, heights, tag ids, surfaces) are constants of `spingi.scenes`, one place for each number.
- **Every problem at once, in one line each.** `SceneError.errors` lists them as `where: what` (`locations.dock.pose.yaww: Extra inputs are not permitted`). `spingi run` and `spingi bench` end such a file as `INVALID_SCENE · <the errors>` with exit status 1, before a robot is started or a run folder is made. The schema is published as `docs/schemas/scene.schema.json`.
- **Geometry is looked at, as warnings.** `spingi.scene_check` applies the tutorial's rules in plane geometry, with the runtime's own rules for the camera's view and for the landmarks `navigate` expects: a place outside the geofence or at its edge; a place inside a box; a route's leg that crosses one; an object no location has in view; a stop that looks at something and has no landmark to read, in a scene that has landmarks. For a plan in its scene: a `navigate` whose leg crosses a box, an `inspect` or a `detect` with nothing of that class in view. Warnings stop nothing: a wall across the way is a mistake in most scenes and the point of `lab_blocked`.
- **A scene can be seen.** `spingi.scene_map` draws it from above as a PNG with Pillow, no OpenGL: surfaces, ramps and raised areas, the fence, obstacles, locations with their heading, objects, tags with the way they face, routes, and the warnings in red.
- **Two commands.** `spingi check <scene> [--plan P] [--robot R] [--strict]` prints what the scene holds, its errors and its warnings; `spingi map <scene> [--plan P] [--out F]` writes the picture.

## Consequences
- **No scene changes.** The six sample scenes and the scenes of the four golden episodes pass the schema unchanged; a test loads every scene of the repository.
- **A scene that ran with a misspelled key no longer runs.** That is the point, and it is a break: such a file now ends as `INVALID_SCENE` naming the key. `spingi replay` of an episode whose `scene.yaml` has one fails the same way.
- **An object's `pose` needs its `z`.** The world loader always required it; the schema says so in one line instead of a traceback.
- **Checks run before the run.** On the samples: nothing on the yard, the warehouse and the test track with their plans; the wall of `lab_blocked` for any plan that walks through it; `workstation_B` outside the fence of `lab_geofence`; in `lab_small`, the shelf stop, which has no tag in view and inspects well only because the dock's tag is two metres behind it.
- **Pillow is a named dependency of the `sim` extra.** It already came with imageio; the map uses its built-in scalable font, so no font file is shipped.
- **Thresholds are judgment.** A leg within 0.3 m of a box counts as crossing it, a place within 0.15 m as touching it, the fence's edge is 0.3 m wide. They come from the robots' widths and from where the samples' stops stand, and will be set again with the first robot.
- **125 new tests**: every misspelled key and impossible value with the line it gives, the checks of the whole scene, every sample and golden scene through the schema, one scene built for each warning and its fix, the segment and box geometry, the map checked on its pixels, both commands, and the run refused before a robot starts.
