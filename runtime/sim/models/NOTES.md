# Simulation models

Each folder is one robot, vendored from https://github.com/google-deepmind/mujoco_menagerie with its own `LICENSE` (BSD-3 by Unitree Robotics for both). Which folder a run loads, and how the adapter moves the model, is a profile in `spingi/robots.py` (ADR-0012). The `_gen_*.xml` files in these folders are scenes generated by `spingi.adapters.sim_mujoco.scene` and are ignored by git.

## unitree_g1

Folder `unitree_g1` of the menagerie. Only `g1.xml`, `scene.xml` and `assets/` are kept. Our changes with respect to the original:

- `g1.xml`: added the `head` camera on the `torso_link` body (position 0.06, 0, 0.40 in the torso frame, looking forward), used by `SimAdapter.get_camera`.

## unitree_go2

Folder `unitree_go2` of the menagerie. Only `go2.xml`, `scene.xml` and `assets/` are kept (not the MJX variant). Our changes with respect to the original:

- `go2.xml`: added the `head` camera on the `base` body (position 0.30, 0, 0.06 in the base frame, looking forward, 90° field of view, where the real Go2 carries its front camera); mesh references renamed from `.obj` to `.stl`.
- `assets/`: the sixteen OBJ meshes converted to binary STL with trimesh, same triangles (27 MB to 9 MB).

The adapter keeps the "home" keyframe (base 0.27 m above the floor, legs bent) and moves the base kinematically, as for the G1.
