# Spingi Viewer

Web replayer for the episodes produced by the runtime (format in [../docs/episode-format.md](../docs/episode-format.md)). Load an episode `.zip` and watch the robot move in the scene, with the synchronized event timeline and the camera frames. Static site: no server, no physics in the browser, deployable on Netlify as is.

## Usage

```bash
npm install
```

```bash
npm run dev
```

Then open http://localhost:5173, drag in a `.zip` produced by `spingi run --zip` or press "Sample episode". A public episode can also be passed with `?url=https://…/episode.zip` (in development use `#url=`, because Vite rejects queries that look like paths). Space starts and stops, left and right arrows move by one second, clicking an event jumps to that instant.

```bash
npm test
```

```bash
npm run build
```

## How it is built

| File | Role |
|------|------|
| `src/episode.ts` | Reads the zip (fflate), YAML (yaml), JSONL; interpolates the pose over time; aligns events and trajectory. No dependency on rendering: it is the candidate to become the reading SDK. |
| `src/world.ts` | Three.js scene from `scene.yaml`: floor, locations, obstacles, objects, robot. MuJoCo coordinates (Z up) inside a rotated group. |
| `src/player.ts` | Replay clock: play, pause, speed, seek. |
| `src/main.ts` | Interface: loading, timeline, event list, frames, camera following the robot. |
| `public/models/g1.glb` | The G1 in the "stand" pose, 1.2 MB, generated by `runtime/scripts/export_g1_glb.py` and compressed with `npm run model:compress` (meshopt, no simplification). |
| `public/samples/` | Sample episode generated by the runtime. |

The model is static: the base moves, the limbs do not. Once the runtime records joints (`joints` in the trajectory) the GLB will need to be exported with the link hierarchy.

## Deploy

`netlify.toml` at the repository root sets `viewer` as the base directory, `npm run build` as the command and `dist` as the publish folder. Connecting the repository to Netlify is enough.

## What is missing

- Head-camera view next to the third-person one.
- Moving objects (the format supports them, the runtime does not write them yet).
- Loading an unzipped folder.
- Comparing two episodes on the same plan.
